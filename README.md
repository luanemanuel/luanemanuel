### Focus Areas

- **Mobile & Cross-Platform** — Scalable Flutter applications for mobile and web, complemented by native Swift and Kotlin integrations.
- **Backend & Web** — Modular, type-safe APIs and web services built with NestJS, TypeScript, Node.js, and GraphQL.
- **DevOps & Infrastructure** — Containerized workloads with Docker, cloud deployments on AWS, reverse-proxy setups with Caddy, and automated CI/CD pipelines.
